경기도 화성시 동탄5동 유권자를 위한 2026-06-03 지방선거 후보 공약 비교 도구.

---

## 금지 표현 (FORBIDDEN — 절대 사용 금지)

다음 표현은 이 스킬 실행 중 **어떤 상황에서도 사용하지 않는다**:

- `1위`
- `가장 적합`
- `추천`
- `승자`
- `점수`
- `더 나은 후보`
- `좋은 후보`

AI는 정보만 제공한다. 판단·추천·순위는 절대 표시하지 않는다.

`/Users/mksoo/Documents/dev/tmp/PolLens/data/meta.json` 파일을 읽는다.

## Step 3: 후보 파일 읽기

사용자가 선택한 선거에 따라 아래 경로의 `.txt` 파일을 **전부** 읽는다.

| 선택 | 경로 |
|------|------|
| 1. 도지사 | `/Users/mksoo/Documents/dev/tmp/PolLens/data/도지사/경기도/` |
| 2. 시장 | `/Users/mksoo/Documents/dev/tmp/PolLens/data/시장/화성시/` |
| 3. 도의원 | `/Users/mksoo/Documents/dev/tmp/PolLens/data/도의원/경기도/` |
| 4. 시의원 | `/Users/mksoo/Documents/dev/tmp/PolLens/data/시의원/화성시/` |
| 5. 교육감 | `/Users/mksoo/Documents/dev/tmp/PolLens/data/교육감/경기도/` |

각 파일은 다음 형식이다:

```
이름: [이름]
기호: [번호]
정당: [정당]
선거: [선거유형] / [선거구]
공약PDF: [url]
선거공보PDF: [url]  ← 있을 수도 없을 수도 있음
수집일: [ISO8601]

---

[원문 텍스트 — PDF에서 추출한 raw 텍스트]
```

파일을 읽은 후:
1. 각 파일의 `기호:` 줄에서 기호번호를 읽어 **기호번호 오름차순**으로 정렬한다.
2. `---` 이후의 raw 텍스트를 AI가 직접 해석하여 공약 목록을 파악한다.
   - 텍스트가 `(PDF 텍스트 추출 불가`로 시작하면 해당 후보는 공약 내용 대신 `선거공보PDF:` 링크를 표시한다.

해당 경로에 `.txt` 파일이 하나도 없으면 다음을 출력하고 중단한다:

```
이 선거 데이터가 없습니다. /pollens-collect 를 실행해주세요.
```

## Step 4: 공약 비교표 출력

기호번호 오름차순으로 정렬된 후보자들의 공약을 아래 형식의 Markdown 표로 출력한다.

형식:

```
## [선거명] 후보 공약 비교

| | 기호 1 · [이름] ([정당]) | 기호 2 · [이름] ([정당]) | ...  |
|--|--|--|--|
| **공약 1** | [공약 제목] | [공약 제목] | ... |
| **공약 2** | [공약 제목] | [공약 제목] | ... |
| **공약 3** | [공약 제목] | [공약 제목] | ... |
| **공약 4** | [공약 제목] | [공약 제목] | ... |
| **공약 5** | [공약 제목] | [공약 제목] | ... |

※ 기호번호 순 정렬 / 판단·추천 없음
```

규칙:
- 열 순서는 기호번호 오름차순으로만 배치한다.
- 공약이 5개 미만인 후보는 해당 셀을 `-`로 채운다.
- PDF 추출 불가 후보는 공약 셀 대신 `(선거공보 링크 참조)`를 표시하고, 표 아래에 링크를 별도 나열한다.
- 공약 제목은 AI가 raw 텍스트를 해석한 결과를 간결하게 기재한다. 평가하거나 의견을 추가하지 않는다.
- 표 외에 어떤 평가·비교·판단도 추가하지 않는다.

## Step 5: 후속 안내

표 출력 후 다음을 묻는다:

```
다른 선거도 볼까요? 이 후보들에 대해 추가 정보를 찾아드릴까요?
```

### 5a. 다른 선거를 선택한 경우

Step 2로 돌아가 선거 목록을 다시 안내한다.

### 5b. 추가 정보를 요청한 경우

다음을 묻는다:

```
어떤 분야가 가장 중요하세요?
(예: 교통, 환경, 복지, 주거, 교육, 경제 등)
```

사용자가 분야를 답하면 WebSearch를 사용해 해당 후보자들의 관련 기사·SNS·과거 발언을 검색한다.

검색 결과를 제시할 때 지켜야 할 규칙:
- 사실 정보만 제시한다.
- 출처(매체명, 날짜)를 함께 표기한다.
- 판단·추천·순위는 절대 표시하지 않는다.
- 금지 표현 목록의 표현을 사용하지 않는다.
