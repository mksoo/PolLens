# PolLens 설계 문서

> 작성일: 2026-05-28  
> 목적: 새 세션에서 컨텍스트 없이 구현을 시작할 수 있도록 설계를 기록

---

## 목적

경기도 화성시 동탄5동 유권자가 2026-06-03 지방선거 후보자의 공약을 빠르게 비교할 수 있는 **개인용 Claude Code 스킬**(`/pollens`)을 만든다.

---

## 전체 구조

```
PolLens/
├── scripts/
│   ├── collect.ts              # CLI 진입점
│   ├── scrapers/
│   │   ├── base.ts             # 공통 Playwright 로직
│   │   ├── governor.ts         # 도지사
│   │   ├── mayor.ts            # 시장
│   │   ├── provincial.ts       # 도의원
│   │   ├── municipal.ts        # 시의원
│   │   └── education.ts        # 교육감
│   └── types.ts                # 공통 타입
├── data/
│   ├── 도지사/경기도/
│   │   ├── 추미애.md           # 기호 1
│   │   └── 김은혜.md           # 기호 2
│   ├── 시장/화성시/
│   │   ├── 홍길동.md
│   │   └── 김철수.md
│   ├── 도의원/동탄제1선거구/
│   │   └── ...
│   ├── 시의원/동탄5동/
│   │   └── ...
│   ├── 교육감/경기도/
│   │   └── ...
│   └── meta.json               # { "collectedAt": "ISO8601" }
└── skills/
    └── pollens.md              # Claude Code 스킬
```

### 디렉토리 규칙

- `data/<선거유형>/` — 선거 유형이 최상위 디렉토리 (도지사, 시장, 도의원, 시의원, 교육감)
- `data/<선거유형>/<지역>/` — 지역이 중간 디렉토리 (경기도, 화성시, 동탄5동 등)
- `data/<선거유형>/<지역>/<후보이름>.md` — 후보자 1명 = 파일 1개
- 장점: 후보별 독립 수집/갱신, 한 후보 실패해도 나머지 보존
- 다른 지역 추가 시 디렉토리 추가 (예: `시장/수원시/홍길순.md`)

## 데이터 수집 (Playwright TypeScript)

### 데이터 소스

- **URL:** https://policy.nec.go.kr
- **방식:** 선관위 공식 선거공보 문서 뷰어의 DOM textLayer 추출
- **근거:** 문서 뷰어가 이미지 위에 선택 가능한 텍스트 레이어를 DOM에 포함함. Ctrl+C로 복사 가능하며 공약 내용이 구조화된 텍스트로 추출됨.

### 탐색 흐름

```
policy.nec.go.kr
  → 선거 유형 선택 (도지사 / 시장 / 도의원 / 시의원 / 교육감)
  → 선거구 필터 (경기도 / 화성시 / 동탄 / 동탄5동)
  → 후보자 목록 수집 { name, ballotNumber, party, documentKey }
  → 후보자별 문서 뷰어 접근 (key로 로드)
  → 전체 페이지 textLayer 텍스트 추출
  → 파싱 → MD 파일 저장
```

> ⚠️ 실제 DOM 셀렉터는 구현 시 Playwright로 직접 탐색 후 확정. 셀렉터는 `base.ts`에 격리하여 변경 시 한 곳만 수정.

### `base.ts` 책임

- Playwright 브라우저 시작/종료 관리
- 문서 뷰어 textLayer 대기 및 텍스트 추출
- 전체 페이지 순회 (페이지 수 자동 감지)

### 각 스크래퍼 책임

- `base.ts`를 상속/사용
- 해당 선거 유형의 후보자 목록 페이지 탐색
- 후보자별 문서 키 수집 후 `base.ts`에 추출 위임
- 파싱된 결과를 MD 포맷으로 반환

### 원문 텍스트 파싱 규칙

실제 복사 확인된 원문 패턴 기반:

| 원문 패턴 | MD 변환 |
|-----------|---------|
| `공약순위: N 제목 : [제목]` | `### 공약 N: [제목]` |
| `□ 목 표` | `**목표**` |
| `□ 이행방법` | `**이행방법**` |
| `□ 이행기간` | `**이행기간**` |
| `□ 재원조달방안 등` | `**재원조달**` |
| `○ [내용]` | `- [내용]` |

### MD 출력 포맷

파일 1개 = 후보자 1명. 파일명은 후보자 이름 (예: `추미애.md`).

```markdown
# 추미애 — 도지사 · 경기도
> 기호: 1 · 더불어민주당 · 수집: 2026-05-28T10:00:00+09:00

---

### 공약 1: 수도권 30분 출근 대전환
**목표**
- ...

**이행방법**
- ...

**이행기간**
- ...

**재원조달**
- ...

### 공약 2: [제목]
...
```

### CLI 사용법

```bash
# 전체 수집 (동탄5동 기준 모든 선거)
npx ts-node scripts/collect.ts

# 특정 선거만
npx ts-node scripts/collect.ts --type 시장 --region 화성시
```

## 캐시 전략

- `data/meta.json` — 마지막 수집 시각 기록
- 스킬 실행 시 `collectedAt` 기준 **24시간** 이내면 캐시 사용
- 24시간 초과 또는 파일 없음 → 자동 재수집
- 선거일(2026-06-03)까지 공약 변경 가능성 낮으므로 24h 캐시로 충분

```json
// data/meta.json
{
  "collectedAt": "2026-05-28T10:00:00+09:00",
  "elections": ["도지사", "시장", "도의원", "시의원", "교육감"]
}
```

## 스킬 설계 (`pollens.md`)

### 실행 흐름

```
1. /pollens 실행
2. 캐시 확인 (data/meta.json)
   - 신선: 바로 진행
   - 없음/만료: "데이터를 수집합니다... (~30-60초 소요)"
              Bash: npx ts-node scripts/collect.ts
3. 선거 목록 안내:
   "경기도 화성시 동탄5동 기준으로
    2026-06-03에 다음 선거가 예정되어 있습니다:
    1. 도지사 — 경기도
    2. 시장 — 화성시
    3. 도의원 — 동탄제1선거구
    4. 시의원 — 동탄5동
    5. 교육감 — 경기도
    어떤 선거부터 볼까요?"
4. 사용자 선택 → 해당 선거구 디렉토리의 모든 후보 MD 파일 읽기
   (예: `data/시장/화성시/*.md` 전체 → 기호번호 오름차순 정렬)
5. 후보자 × 공약 비교표 제시 (기호번호 오름차순)
6. "다른 선거도 볼까요? 이 후보들에 대해 추가 정보를 찾아드릴까요?"
   - 다른 선거 → 3번으로
   - 추가 정보 → "어떤 분야가 가장 중요하세요?" → WebSearch → 사실만 제시
```

### 비교표 포맷

```
## 화성시장 후보 공약 비교

| | 기호 1 · 홍길동 (민주당) | 기호 2 · 김철수 (국민의힘) |
|--|--------------------------|---------------------------|
| **공약 1** | 수도권 30분 출근 대전환 | ... |
| **공약 2** | ... | ... |
| **공약 3** | ... | ... |
| **공약 4** | ... | ... |
| **공약 5** | ... | ... |

※ 기호번호 순 정렬 / 판단·추천 없음
```

### 제약 조건 (절대 준수)

- `"1위"`, `"가장 적합"`, `"추천"`, `"승자"`, `"점수"` 등 표현 사용 금지
- 후보 정렬: 기호번호(ballotNumber) 오름차순만 허용
- 사실 정보만 제시, 판단·추천 없음

## 에러 처리

| 상황 | 대응 |
|------|------|
| Playwright 미설치 | "Playwright가 필요합니다: `npm install && npx playwright install chromium`" |
| 스크래퍼 실패 (네트워크 등) | "데이터 수집에 실패했습니다. policy.nec.go.kr 접속을 확인하거나 잠시 후 다시 시도해주세요." |
| 특정 선거 데이터 없음 | "이 선거 데이터가 없습니다. `npx ts-node scripts/collect.ts`를 다시 실행해주세요." |
| 후보자 공약 미등록 | "이 후보의 공약이 아직 등록되지 않았습니다." 로 명시 |

## 미결 사항 (구현 시 확정)

1. **DOM 셀렉터** — Playwright로 policy.nec.go.kr 탐색 시 실제 textLayer 클래스명 확정
2. **후보자 목록 페이지 URL 패턴** — 선거 유형별 탐색 경로 확정
3. **동탄제1선거구** — 동탄5동이 속한 도의원 선거구명 확인 필요

## 스킬 배포

`skills/pollens.md`를 Claude Code가 인식하려면 `~/.claude/commands/`에 등록 필요:

```bash
# 심볼릭 링크 (수정 시 자동 반영)
ln -s /Users/mksoo/Documents/dev/tmp/PolLens/skills/pollens.md \
      ~/.claude/commands/pollens.md
```

등록 후 Claude Code에서 `/pollens` 로 실행.
