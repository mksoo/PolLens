# pollens-collect UX 개선 설계

## 변경 범위

`.claude/commands/pollens-collect.md` 단일 파일 수정. 스크립트 코드 변경 없음.

## Path A

"복사해서 붙여넣어 주세요" → "캡쳐해서 붙여넣어 주세요"

이유: 선관위 사이트(info.nec.go.kr)에서 텍스트 복사가 막혀 있으므로, 스크린샷으로 전달하도록 안내 문구 수정.

## Path B

### 기존 흐름
1. 시도 질문
2. 시군구 질문
3. 읍/면/동 질문
→ `resolveDistrictByAddress(sido, sigungu, emd)` 호출

### 신규 흐름
1. "주소를 입력해 주세요 (도로명/지번 모두 가능)" 한 번에 질문
2. 입력이 도로명주소처럼 보이면: Claude가 WebSearch로 해당 주소의 읍면동 조회
3. 검색 결과를 사용자에게 보여주고 확인 요청
4. 확인된 시도/시군구/읍면동으로 `resolveDistrictByAddress` 호출 (기존과 동일)

### 주소 처리 규칙

| 입력 예시 | 처리 방법 |
|---|---|
| `경기도 화성시 동탄5동` | 시도/시군구/읍면동 직접 파싱, WebSearch 불필요 |
| `경기도 화성시 동탄대로 537` | WebSearch로 읍면동 조회 후 확인 |
| `화성시 동탄대로 537` | WebSearch로 시도+읍면동 조회 후 확인 |

도로명("로", "길") 또는 건물번호가 포함된 입력은 WebSearch 경로로 처리한다.
WebSearch 쿼리: `"{입력 주소}" 행정동` 형태로 검색해 시도/시군구/읍면동 추출.
