# PolLens 스킬 재구성 설계

**날짜:** 2026-05-30  
**목표:** `/pollens`를 오케스트레이터로 전환하고, 공약 비교 분석을 `/pollens-compare` 서브에이전트로 분리한다.

---

## 문제

현재 `/pollens` 스킬은 오케스트레이션(흐름 관리)과 분석(PDF 읽기 + 비교표 출력)을 하나의 스킬에서 담당한다. 역할이 혼재되어 있어 재사용성이 낮고, 향후 분석 기능 변경 시 흐름 로직까지 같이 수정해야 한다.

---

## 해결 방향

3개 스킬로 책임을 명확히 분리한다.

| 스킬 | 역할 | 변경 여부 |
|------|------|-----------|
| `/pollens` | 오케스트레이터 — 대화 흐름 전체 관리 | 수정 |
| `/pollens-collect` | 서브에이전트 — NEC에서 PDF 수집 | 변경 없음 |
| `/pollens-compare` | 서브에이전트 — PDF 읽기 + 비교표 출력 | 신규 |

---

## 각 스킬 설계

### `/pollens` (오케스트레이터)

**책임:** 대화 흐름 소유. 데이터 유효성 확인, 선거 선택 UI, 루프, 추가 정보 검색.

**흐름:**

```
1. data/meta.json 읽기
2. 파일 없음 또는 collectedAt > 24h → "pollens-collect 실행하세요" 후 종료
3. 선거 목록 5개 출력 (도지사/시장/도의원/시의원/교육감)
4. 사용자 선택 대기
5. /pollens-compare 호출 (electionType 파라미터 전달)
6. 비교표 출력 완료 후:
   A. "다른 선거 볼까요?" → 3으로 루프
   B. "추가 정보 검색?" → WebSearch로 후보별 기사/SNS 검색 (오케스트레이터 직접 처리)
   C. 종료
```

**판단 금지 규칙** 유지: 1위, 추천, 승자, 점수 등 평가 표현 절대 금지.

---

### `/pollens-compare` (신규)

**책임:** 단일 작업 실행기. `electionType`을 입력받아 비교표 하나를 출력하고 종료.

**인터페이스:**
- 입력: 대화 컨텍스트에서 `electionType` 값 (도지사|시장|도의원|시의원|교육감)
- 출력: Markdown 비교표

**흐름:**

```
1. data/meta.json 읽기
2. electionType 해당 후보 필터링
3. 후보 없음 → "이 선거 데이터가 없습니다. /pollens-collect 실행하세요."
4. ballotNumber 오름차순 정렬
5. 각 후보 PDF 읽기:
   - pdfPath 있음 → Read(pdfPath)
   - pdfPath 없고 pbinfoPdfPath 있음 → Read(pbinfoPdfPath) (이미지 기반, 실패 시 "(선거공보 링크 참조)")
   - 둘 다 없음 → "(공약 파일 없음)"
6. 비교표 출력 (기호번호 오름차순)
7. 종료 (대화 없음)
```

**비교표 형식:**

```
## [선거명] 후보 공약 비교

| | 기호 1 · 이름 (정당) | 기호 2 · 이름 (정당) | ... |
|--|--|--|--|
| **공약 1** | ... | ... | ... |
...

※ 기호번호 순 정렬 / 판단·추천 없음
```

**판단 금지 규칙** 동일 적용.

---

### `/pollens-collect` (변경 없음)

기존 스킬 그대로 유지.

---

## 현재 pollens.md와의 차이

| | 현재 | 변경 후 |
|--|--|--|
| Step 1 (캐시 확인) | pollens.md | pollens.md (유지) |
| Step 2 (선거 목록) | pollens.md | pollens.md (유지) |
| Step 3~4 (PDF + 표) | pollens.md | → pollens-compare.md로 이전 |
| Step 5 (후속 안내) | pollens.md | pollens.md (유지, 루프 추가) |

---

## 성공 기준

- `/pollens` 단독 실행 시 전체 흐름(수집 안내, 선거 선택, 비교, 루프, 추가 검색)이 동작한다.
- `/pollens-compare`는 electionType 없이 호출되면 오케스트레이터에게 위임 (단독 실행 시 electionType 요청).
- `/pollens-collect`는 동작 변화 없다.
- 금지 표현이 어느 스킬에서도 출력되지 않는다.
